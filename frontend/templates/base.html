NIDS Help Guide

Getting Started

1. Select a network interface from the dropdown in the top bar

2. Click "START CAPTURE" to begin monitoring network traffic

3. View live alerts on the Dashboard as they are detected

Understanding Alerts

HIGH - Critical threats requiring immediate attention

MEDIUM - Suspicious activity that should be investigated

LOW - Informational alerts for awareness

NORMAL - Legitimate network traffic (no threat)

Attack Types

  • DoS - Denial of Service (overwhelming a target with traffic)
  • Probe - Port scanning and network reconnaissance
  • R2L - Remote to Local (unauthorized access attempts)
  • U2R - User to Root (privilege escalation attempts)
  • Normal - Regular network activity

Dashboard Features

  • Real-time charts - Traffic timeline and attack distribution
  • SHAP explanations - Why the ML model flagged an attack
  • Export CSV - Download alerts for offline analysis
  • Historical analytics - Attack patterns and ML performance
